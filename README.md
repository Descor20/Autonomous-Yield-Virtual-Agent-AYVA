# AYVA

The agentic project: Autonomous Yield Virtual Agent

## Description

This project is a project about the conception of a personnal home agent to use freely.
It will be composed of the features of listenning to the user and replying by speaking.
It can also be more interactive by having a small visual frontend to open.
